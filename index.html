GitHub Private Repository Se Live Website Kaise Banayein?

💡 Sabse Zaroori Baat (Private Repo Tip): GitHub ke Free account mein GitHub Pages sirf Public repo par chalta hai. Lekin agar aap apni repository Private rakhna chahte hain, toh aap Vercel.com ya Netlify.com ko GitHub se connect karke 100% FREE mein apni Private Repo ko publish kar sakte hain!

Step 1: Code Ko index.html File Mein Save Karein

1. Pehle website mein apna final Phone Number update kar lein.

2. Is poore code ko copy karke apne computer/laptop par Notepad ya VS Code mein paste karein aur file ka naam bilkul index.html (small letters mein) rakh kar save karein.

Step 2: GitHub Par Private Repository Banayein

1. github.com par login karein aur upar right side mein + (Plus) icon dabayein → New repository par click karein.

2. Repository name mein likhein: grkn-ev-website

3. Neeche Private option select karein aur Create repository button daba dein.

4. Agle page par "uploading an existing file" link par click karein, apni index.html file drag & drop karein, aur neeche green Commit changes button daba dein.

Step 3: Private Repo Se Website Ko Live Publish Karein (Vercel - 100% Free)

1. vercel.com (ya netlify.com) par jayein aur "Continue with GitHub" karke login karein.

2. Add New → Project par click karein aur apni private repo grkn-ev-website ko select karke Import dabayein.

3. Seedha Deploy button par click karein. Sirf 30 seconds mein aapki website live ho jayegi (jaise https://grkn-ev-website.vercel.app)!

Step 4: Apna Custom Domain (.com / .in) Kaise Jodein?

1. GoDaddy, Hostinger ya Namecheap se apna domain (jaise grknevinfrastructure.com ya grknev.in) khareedein.

2. Vercel dashboard mein apne project ke Settings → Domains mein jaakar apna domain naam daal kar Add karein.

3. Vercel aapko ek A Record (76.76.21.21) aur CNAME (cname.vercel-dns.com) dega—bas use apne GoDaddy/Hostinger ke DNS settings mein paste kar dein. 15 minute mein aapki website Free SSL (https://) ke saath aapke official domain par chalne lagegi!

Step 5: Future Mein Website Update Kaise Hogi?

Jab bhi aapko website mein koi text, phone number ya naya project add karna ho, bas apne GitHub Private Repo mein jaakar index.html ke pencil (Edit) icon par click karein, change karein aur Commit changes dabayein—aapki live website 10 seconds mein automatically update ho jayegi!
